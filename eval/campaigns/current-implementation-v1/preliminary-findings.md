# Findings for the paper revision

The manuscript's historical `715a9db0` plus working-tree description should be
replaced by the exact freeze and configuration table in this campaign. The
current measurements support one coherent results section, with three explicit
qualifications.

First, headline protection currently applies to the immutable-language, Docker,
and object-broker dispatchers. Direct `LinuxSandboxExecutor` has closed
admission, Cedar/profile checking, Lean lifecycle checking, Landlock and audit,
but the sealed runtime-MAC implementation refuses that dispatcher. The paper
must present this as an implementation gap, not silently treat the routes as
equivalent.

Second, the matched Pandas v19 rerun is 50/50 for A, B and C, whereas C-closed
v21 is 45/50. The five misses are mandatory non-finite-output refusals, not lost
records or verifier defects. They should remain utility failures until the
trusted state-transport contract prevents Pandas from reconstructing NaN.

Third, the retained evidence explains but does not uniquely attribute the older
upstream change from 29/50 to 50/50. The model, seed, tasks and data are stable;
the successful cohort adds request preservation, recursive JSON transport,
period aggregation and three bounded graph retries. One-factor serializer and
period probes establish those earlier failure mechanisms, but the repository
does not contain a complete factorial rerun assigning a fraction of the 21
recovered tasks to each change.

The central baseline result is the Alice/Bob composition: denying the whole
database is nonfunctional, while exposing the file or adding only call-level
authorization preserves Alice's work but permits forbidden effects. The
record-aware parent mediator plus confined worker is the tested configuration
that preserves all allowed operations with zero Bob/direct-file effects.

The Lean contribution should be stated as five exact theorems over a finite
route model. The retained audit costs are 26.960856 s to build, 5.336394 s for
the kernel audit, and 83.467999 s for Lean's own kernel replay. Runtime and OS
refinement remain assumptions. Because no prospective origin log establishes
that the Unicode translation counterexample was first found by modeling, the
paper should not claim a modeling-found bug; reproduced runtime and serializer
regressions are classified as testing-found.
