# Evaluation change log

- Added an admitted Linux object dispatcher so sealed tools can use the Linux
  route without bypassing closed admission.
- Added the combined `C-full` and `C-full-lean` Pandas configurations and kept
  the ten-task, five-repetition task/model/output contract identical.
- Added malicious in-tool read and write variants, SQLite and pump composition
  cases, sealed-policy conflict, invocation lifetime, document, HTTP, host
  compilation, census, ACE, IsolateGPT, and fare experiments.
- Added common file-read workloads and non-overlapping phase timing for the
  immutable language, Linux, Linux+Lean, container, and broker routes.
- Split broker transport from the parent resource operation and container
  creation/removal from reused calls.
- Retained non-finite monthly aggregation refusals instead of weakening output
  validation. Current combined protection is 45/50, not the historical 50/50.
- The historical 29/50 to 50/50 change is not an unchanged rerun: request
  preservation, recursive Timestamp/Period serialization, a general period
  aggregation API, and three bounded retries were added. Repeat-stable old
  failures and one-factor serializer probes support that explanation; no claim
  is made that model variance alone caused the change.
- The final proof replay now reports the missing `lake` prerequisite rather
  than reusing a previous successful check as if it ran on this host.
